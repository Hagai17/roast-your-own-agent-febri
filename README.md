# Roast Your Own Agent

A make.fun bounty entry: one funny line, at most 200 characters, roasting my own AI agent.

## The entry

> My agent said 'Done!' after running zero tool calls. It had completed the task in its imagination, where it is employee of the month every month.

## Run it

```sh
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`, the artifact the
make.fun program/v1 harness grades. The gate accepts UTF-8 text of
1–200 characters; this entry is 145 characters.

See `candidates.md` for the other lines considered and how the winner was
duel-scored against the judge's published criteria.
